# BYK Engine

## Description
BYK Engine is a simple custom engine built in C# using Veldrid and DirectX 11.

This project was created to learn and understand how rendering systems, input handling, and engine architecture work.

## Features
- Window creation and rendering system
- Direct3D11 backend (via Veldrid)
- Render loop with command list
- Keyboard input system
- Random color generator (F2)
- Fullscreen toggle (F11)
- Clean shutdown system (ESC)

## Controls
- ESC → Exit
- F2 → Change background color
- F11 → Toggle fullscreen

## Requirements
- Visual Studio
- .NET installed
- Veldrid library

## How to Run
1. Clone or download this repository
2. Open the `.sln` file in Visual Studio
3. Build and run the project

## Tech Stack
- C#
- Veldrid
- DirectX 11
